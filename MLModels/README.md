# Cyber Attack Detection System Using Machine Learning

An Intelligent Intrusion Detection System (IDS) developed as a Software Engineering Final Year Project. This system analyzes network packet data in real-time using supervised Machine Learning algorithms deployed via a Flask web interface.

## 🚀 Key Features
* **Real-time Packet Examination:** Upload PCAP or CSV files to detect benign vs. malicious traffic.
* **ML Model Integration:** Uses trained models (Support Vector Machine, Decision Tree, Random Forest, Naive Bayes, and Logistic Regression) to categorize threats.
* **Interactive Dashboard:** Visual summaries of network traffic, threat types, and confidence scores.
* **User Authentication:** Secure login system with role-based access control.

## 🛠️️ Tech Stack
* **Language:** Python
* **Web Framework:** Flask
* **ML Libraries:** Scikit-Learn, Pandas, NumPy
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite
